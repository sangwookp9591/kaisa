Current deliberate differences from the design, each marked ◐ below: **no separate daemon or keeper process and no control server** (the CLI runs the engine in its own process, so "daemon restart keeps attempts" is "the next `kaisa` start ends a leftover agent, preserves its work and reclaims it"); agents run with captured stdio, not a PTY; the outbox is built and tested but not on the run path; leases and stall detection are not used; there is no OS-level single ledger writer; profile confirmation and dirty-tree choice are not in the run path; MCP version checking is missing; two named tests are absent. There is no signed per-OS distribution in this repository (FR-01). |

### T01 ◐ Test conventions applied to existing code

> Review 2026-10-31: the three rules are not met everywhere. - **Acceptance.** Every test in the workspace satisfies the three rules, and CI is green.
