## Tasks

### T01 ☑ Test conventions applied to existing code
- **Requirement.** NFR-06, FR-02, FR-03.
- **Change.** Rename the existing tests to condition-and-expectation sentences. Replace magic numbers with named constants,
  for example `EXIT_SUCCESS` and `MAX_SUFFIX_LEN`. Build ID text through domain helpers.
- **Acceptance.** Every test in the workspace satisfies the three rules, and CI is green.

### T02 ☑ Domain: event envelope and sequence
- **Requirement.** FR-04 (part).
- **Change.**
  - `Sequence` newtype with `FIRST` and `next()`.
  - `EventKind` enum (`#[non_exhaustive]`).
  - `Event { sequence, kind, subject, payload_version }`.
  - The canonical byte encoding used for hashing. It must be deterministic and independent of field order.
- **Tests.**
  - `the_first_sequence_is_followed_by_the_second_sequence`
  - `the_canonical_bytes_of_an_event_are_the_same_on_every_call`
  - `events_that_differ_only_in_subject_have_different_canonical_bytes`

### T03 ☑ Domain: attempt state axes and legal transitions
- **Requirement.** FR-05.
- **Change.**
  - Four axes: `Execution`, `Outcome`, `Verification`, `Cleanup` (architecture §5.1).
  - A transition function that returns `Result<_, IllegalTransition>`.
  - `Unknown` can never move to a new start.
- **Scope note.** `Quiescing`/`Quiesced` will be added with worker failover (M2). The verification sub-states (`Running`, `Passed`, `Failed`, `Tampered`) will be added with the Verify Gate (M1). Variants are added only when a task uses them.
- **Tests.**
  - `an_admitted_attempt_can_start_running`
  - `an_exited_attempt_cannot_start_running_again`
  - `an_attempt_in_unknown_state_cannot_be_restarted_without_proof`
  - `a_zero_exit_completes_the_outcome_but_leaves_verification_not_started`
  - `cleanup_cannot_reclaim_before_preservation_has_a_receipt`

### T04 ☑ Ledger: hash chain (pure)
- **Requirement.** FR-04.
- **Change.**
  - `ChainHash` (blake3) computed as `hash(prev_hash ‖ canonical_bytes)`.
  - `GENESIS` constant.
  - `verify_chain()` returns the first broken sequence.
- **Tests.**
  - `a_chain_built_from_recorded_events_verifies_cleanly`
  - `editing_a_recorded_event_breaks_the_chain_at_that_event`
  - `removing_an_event_from_the_middle_is_reported_as_a_gap_at_its_position`
  - `an_empty_chain_verifies_cleanly`
  - `swapping_two_events_breaks_the_chain_at_the_earlier_position`
